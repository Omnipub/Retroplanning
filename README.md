# Retroplanning Generator  
Outil de génération de rétroplannings de production personnalisés.

## Fonctionnalités
- Génération de PNG haute résolution
- Formulaire personnalisable (4 étapes)
- Paiement sécurisé via PayPal
- Pied de page personnalisé

## Déploiement  
Déployé sur Render.com lié au domaine retroplanning.eu
